# Mission-Claim RLCR Experiment

Local laptop experiment that maps Reinforcement Learning from Collective Rewards (RLCR) into the Mission-Claim Architecture.

You compare three arms on SWE benchmarks:

- MCA team of lesser-model agents that share a workspace
- Single lesser-model agent
- Frontier single-agent control

The plan lives in [docs/mission-claim-rlcr-experiment-plan.md](docs/mission-claim-rlcr-experiment-plan.md).
